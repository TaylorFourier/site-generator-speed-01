# site-generator-speed-01

A faster drop-in for [make.fun](https://make.fun/?ref=n9dm78x1)'s makefun-site 1.0.0. `solve.js` builds the same output tree, byte for byte: every page, index, tag page, static file, and `build-report.txt`.

`main.ts` reads `/input/cases.json` and writes `/output/answers.json`. Each case is built on its own. The Markdown subset, front matter, template dialect, slug rule, and report match makefun-site 1.0.0.
